# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.
Disagreements are about code and ideas, never about people.

Report unacceptable behavior privately to the maintainer via GitHub
(@Bhav-ikkk). Reports are handled confidentially.
