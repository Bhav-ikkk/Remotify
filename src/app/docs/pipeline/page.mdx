## Algorithm (what actually runs)

1. **Gate** — scheduler enabled; refuse if `isRunning` (lock).  
2. **Open RunHistory** — status `running`.  
3. **Scrape** — `Promise.allSettled` over `SCRAPER_REGISTRY`.  
4. **Flatten + normalize** each successful payload.  
5. **Dedupe** against in-batch + recent DB jobs.  
6. **Quality prefilter** — drop junk titles / non-remote noise; rank auto-ATS.  
7. **Cap** — `max_jobs` setting; cron path further limits for duration.  
8. **Build AI brief** from active `CandidateProfile` (or legacy target string).  
9. **Score sequentially** via `AIService` / Gemini with delay + time budget.  
10. **Upsert jobs** by `applyUrl`.  
11. **Notify** top matches ≥ `min_match_score` (default 85), mark `isNotified`.  
12. **Enqueue** eligible applies ≥ `apply_min_score` (default 75) if apply enabled.  
13. **Telegram apply bump + digest text** when queue moves.  
14. **Run report** to Telegram.  
15. **Close scheduler** — clear `isRunning`, set next run, finalize RunHistory.

## Cron budgets (Hobby reality)

| Knob | Typical cron value | Why |
| --- | --- | --- |
| Jobs scored | **12** | Fit under ~60s `maxDuration` |
| AI wall clock | **~40s** | Leave room for notify/enqueue |
| Inter-job delay | **~400ms** | Reduce Gemini 429s |

Manual / script runs may use higher `max_jobs` from Settings — still sequential AI.

## Failure taxonomy

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| `jobsParsed` high, `jobsProcessed` 0 | Quality filter too strict / no Gemini key | Check Settings + quality allowlist |
| All sources 0 | Network / blocked HTML | Run `npm run test:scrapers`; check Zyte for Wellfound |
| Partial status | Some scrapers rejected | Expected; inspect RunHistory `errors` |
| No Telegram | Missing token/chat | Settings test Telegram |
| No enqueue | `apply_enabled` false / quota 0 / scores &lt; 75 | Settings + score backfill |
| Scheduler stuck running | Crash mid-run | Clear `isRunning` in DB/UI |

## Secrets resolution during pipeline

Gemini key prefers **runtime env** (`GEMINI_API_KEY`) then Settings `ai_api_key`, ignoring placeholders like `changeme` / `test-gemini`. Same pattern for Telegram/Zyte elsewhere.
