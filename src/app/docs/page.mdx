# Remotify documentation

Remotify is a self-hostable remote-job system that scrapes boards, scores fit against your profile, alerts you on Telegram with tailored ATS resumes, and auto-applies on Greenhouse / Lever / Ashby through a **local Playwright worker**.

**Product thesis:** Apply with intent, not volume.

<Callout title="What these docs are">
  This is the live system handbook — architecture, technology decisions, data contracts, code ownership, operations, and the roadmap. Every diagram is grounded in real files under <code>src/</code>.
</Callout>

## Mental model in one picture

<Figure caption="Brain runs on Vercel/Neon. Hands run on your PC. Queue is the contract between them.">

- **Brain** decides what is worth applying to (scrape, score, notify, enqueue).
- **Hands** fill ATS forms with a real browser (Playwright) so Vercel never runs Chromium.
- **Queue** (`Application` rows + claim/report APIs) is the durable handshake.

## What the product deliberately refuses

- LinkedIn / Indeed bot spam and mass spray applications  
- Inventing resume facts during AI tailor  
- Running Playwright on serverless (Hobby `maxDuration` + browser weight)  
- Silent scraper failures that kill the whole run (sources soft-fail to `[]`)
